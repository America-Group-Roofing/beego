# Auditoría de imágenes originales

Los archivos en \`assets/\` son **originales de trabajo**. Esta carpeta no se publica automáticamente con Astro.

La auditoría genera \`inventory.json\` (dimensiones, formatos, transparencia y SHA-256) y una hoja \`contact-sheet.jpg\` con miniaturas para revisión.

**Advertencias:** el inventario automatizado no certifica fidelidad al Brand Book V2, calidad comercial, licencias, aprobación de un render, ni existencia de una estación. No sirve como autorización de publicación. No se alteran los PNG/WebP originales.

Las imágenes de estaciones, devoluciones y fotografías conceptuales no deberán publicarse como instalaciones o operaciones reales. Los SVG en \`assets/\` están considerados aparte en el registro curatorial.

Las versiones definitivas para servir al navegador se incorporarán únicamente en \`public/assets/\` o \`src/assets/\`, según su uso y estado aprobado.
