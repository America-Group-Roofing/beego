# BeeGo · Assets web

Los assets de producción deben ser fieles al Brand Book V2.0.

- Usar archivos de logotipo oficiales, sin redibujar ni deformar.
- El power bank amarillo multivista de la página 20 del manual es una referencia de diseño, no certificación técnica.
- Pendientes de incorporación: logo digital optimizado, producto para hero, vistas oficiales, fotografías urbanas con derechos de uso y estaciones conceptuales correctamente identificadas.
- No cargar al repositorio público estudios internos, archivos con información de clientes, cotizaciones o datos comerciales confidenciales.
- Los diseños previos del sitio son referencias visuales, no assets aprobados para web.

No se añadió un logo recreado ni una imagen genérica en la base inicial.
